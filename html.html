What is HTML?

HyperText Markup Language (HTML) is the standard language for structuring web content. It uses a system of elements represented by tags (e.g., <p>, <h1>, <a>) to describe the meaning and structure of content. Browsers parse HTML to build the Document Object Model (DOM), which is then rendered visually.

HTML Document Structure

Every HTML document begins with <!DOCTYPE html> declaring the version, followed by the root <html> element containing a <head> (metadata, title, links to CSS/JS) and a <body> (all visible content). Elements are nested inside each other, forming a tree structure called the DOM.

Semantic HTML

HTML5 introduced semantic elements that convey meaning: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>. Using semantic tags improves accessibility (screen readers understand the content), SEO (search engines can better index the page), and code readability.

HTML and CSS and JavaScript

HTML, CSS, and JavaScript are the three core technologies of the Web. HTML provides structure and content; CSS (Cascading Style Sheets) handles visual presentation (colours, fonts, layout); JavaScript adds interactivity and dynamic behaviour. They are kept separate for maintainability.

HTML Evolution

HTML has evolved from HTML 1.0 (1991) through HTML 2.0, 3.2, 4.01, XHTML, to HTML5 (2014). HTML5 added native audio/video, canvas, geolocation, local storage, web workers, and new semantic elements. The HTML Living Standard is now maintained by WHATWG with ongoing updates.
