Web 3.0

Web 3.0 envisions the next evolution of the Web — a decentralised, trustless, machine-readable network powered by blockchain technology, AI, and semantic data standards, aiming to give users ownership of their data.

THE SEMANTIC & DECENTRALISED WEB

Web 3.0 ecosystem — blockchain, AI, semantic web, DeFi, NFTs interconnected

What is Web 3.0?

Web 3.0 is a contested term with two intersecting meanings. Tim Berners-Lee's original vision (Semantic Web) describes a machine-readable Web where data is structured and linked so AI agents can process it intelligently. The blockchain/crypto community uses Web3 to describe a decentralised Web built on distributed ledgers, eliminating dependence on centralised platforms.

The Semantic Web Vision

The Semantic Web uses technologies like RDF (Resource Description Framework), OWL (Web Ontology Language), and SPARQL to add meaning to data. Linked Data allows disparate databases to connect. Schema.org markup (used by Google, Bing) is a practical implementation, enabling rich search results.

Blockchain and Decentralisation

Web3 proponents argue that Web 2.0's centralisation — where Facebook, Google, and Amazon control vast amounts of user data — is problematic. Blockchain provides a trustless, distributed ledger. Smart contracts (self-executing code on Ethereum) enable decentralised applications (dApps) that operate without central authorities.

Key Web3 Concepts

DeFi (Decentralised Finance) recreates financial services without banks. NFTs (Non-Fungible Tokens) enable digital ownership and provenance. DAOs (Decentralised Autonomous Organisations) allow community governance. Crypto wallets (MetaMask) replace traditional logins. IPFS (InterPlanetary File System) decentralises content hosting.

Challenges and Criticisms

Web3 faces significant challenges: blockchain scalability (Bitcoin processes ~7 transactions/second vs Visa's 24,000), energy consumption, usability complexity, regulatory uncertainty, widespread scams, and speculative bubbles. Critics argue it replaces platform centralisation with infrastructure centralisation (Infura, OpenSea).
