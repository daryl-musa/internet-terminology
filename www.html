World Wide Web

The World Wide Web (WWW) is an information system enabling documents and resources to be accessed over the Internet via web browsers — the most recognised face of the Internet.

World Wide Web

WWW

Global hyperlinked document network — the World Wide Web

What is the World Wide Web?

The World Wide Web is a system of interlinked hypertext documents and multimedia content accessed through the Internet using a web browser. It was invented by Sir Tim Berners-Lee in 1989 and made publicly available in 1991, originally to facilitate information sharing among scientists at CERN.

How it Works

The Web operates on a client-server model. A user's browser (client) sends an HTTP request to a web server, which responds with HTML documents, images, stylesheets, and scripts. Hyperlinks allow navigation between resources, creating the interconnected 'web' of information.

WWW vs the Internet

A common misconception is that the Web and the Internet are the same. The Internet is the global network infrastructure (cables, routers, protocols), while the WWW is a service that runs on top of it. Other Internet services include email, FTP, and VoIP.

Key Components

Three core technologies underpin the Web: HTML (HyperText Markup Language) for structuring content, HTTP (HyperText Transfer Protocol) for data transfer, and URLs (Uniform Resource Locators) for addressing resources. Together these form the architecture Tim Berners-Lee designed.

Significance

The WWW democratised information access globally, enabling billions of people to publish, share, and consume content. It has transformed commerce, education, communication, and governance, making it one of the most transformative technologies in human history.
