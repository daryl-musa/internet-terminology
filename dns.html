Domain Name Server

The Domain Name System (DNS) translates human-readable domain names (like www.google.com) into machine-readable IP addresses — enabling users to use memorable names instead of numerical addresses.

What is DNS?

The Domain Name System (DNS) is a hierarchical, distributed naming system that maps domain names to IP addresses. Without DNS, users would need to memorise IP addresses like 142.250.80.46 instead of typing google.com. It operates on UDP port 53 and processes billions of queries daily.

DNS Resolution Process

When you type a URL, your browser checks its local cache. If not found, it queries a recursive resolver (usually provided by your ISP or a public DNS like 8.8.8.8). The resolver then queries a root name server, which directs it to the appropriate TLD server (.com, .org), which in turn directs it to the authoritative name server for the specific domain, which returns the IP address.

DNS Record Types

DNS stores different record types: A records map a domain to an IPv4 address; AAAA records to IPv6; CNAME records create aliases; MX records specify mail servers; TXT records store text data (used for verification and SPF); NS records identify name servers; and PTR records enable reverse lookups.

DNS Hierarchy

DNS is organised as a tree. At the root are 13 sets of root servers distributed globally. Below are TLD servers (.com, .net, .org, country codes). Below these are second-level domains (google, amazon), and further subdomains (mail.google.com).

DNS Security

DNS was originally designed without security. DNSSEC (DNS Security Extensions) adds cryptographic signatures to verify responses. DNS over HTTPS (DoH) and DNS over TLS (DoT) encrypt DNS queries, preventing eavesdropping and man-in-the-middle attacks.
