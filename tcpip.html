TCP/IP

TCP/IP is the foundational suite of communication protocols used to interconnect network devices on the Internet — defining how data is packaged, addressed, transmitted, routed, and received.

What is TCP/IP?

TCP/IP (Transmission Control Protocol/Internet Protocol) is a set of rules governing how data is transmitted across networks. It is the backbone of Internet communication, developed in the 1970s by Vint Cerf and Bob Kahn through DARPA research.

The Two Core Protocols

TCP (Transmission Control Protocol) ensures reliable, ordered delivery of data by breaking messages into packets, confirming receipt, and requesting retransmission of lost packets. IP (Internet Protocol) handles addressing and routing — each packet carries source and destination IP addresses so routers can forward it correctly.

The Four-Layer Model

TCP/IP is described in four layers: the Application Layer (HTTP, FTP, SMTP), the Transport Layer (TCP, UDP), the Internet Layer (IP, ICMP), and the Network Access Layer (Ethernet, Wi-Fi). Each layer adds headers to data (encapsulation) as it moves down the stack.

TCP vs UDP

TCP is connection-oriented and reliable, used for web browsing, email, and file transfer where accuracy matters. UDP (User Datagram Protocol) is connectionless and faster, used for live streaming, gaming, and VoIP where speed is prioritised over guaranteed delivery.

IP Addressing

Every device on the Internet is assigned an IP address. IPv4 uses 32-bit addresses (e.g., 192.168.1.1), supporting about 4.3 billion addresses. IPv6 uses 128-bit addresses to overcome IPv4 exhaustion, supporting a virtually limitless address space.
