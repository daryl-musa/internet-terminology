Hypertext Transfer Protocol

HTTP (HyperText Transfer Protocol) is the application-layer protocol that defines how messages are formatted and transmitted between web browsers and servers — the language of the World Wide Web.

HTTP methods (verbs) and common response status codes

What is HTTP?

HTTP is a request-response protocol in the client-server computing model. A client (browser) sends an HTTP request to a server; the server processes it and returns an HTTP response. Originally designed by Tim Berners-Lee in 1989-1991, it has evolved through versions 1.0, 1.1, 2, and 3.

HTTP Methods

HTTP defines several request methods (verbs): GET retrieves data without side effects; POST submits data to be processed; PUT replaces a resource; PATCH partially updates a resource; DELETE removes a resource; HEAD retrieves headers only; OPTIONS describes communication options. GET and POST are the most common.

HTTP Status Codes

Responses include three-digit status codes indicating outcome. 1xx are informational; 2xx indicate success (200 OK, 201 Created); 3xx indicate redirects (301 Moved Permanently, 304 Not Modified); 4xx indicate client errors (400 Bad Request, 401 Unauthorized, 404 Not Found); 5xx indicate server errors (500 Internal Server Error).

HTTPS and TLS

HTTPS (HTTP Secure) adds a TLS (Transport Layer Security) encryption layer beneath HTTP. It provides confidentiality (data is encrypted), integrity (data cannot be tampered with), and authentication (the server's identity is verified via certificates). Modern browsers flag HTTP-only sites as 'Not Secure'.

HTTP/2 and HTTP/3

HTTP/2 introduced multiplexing (multiple requests per connection), header compression (HPACK), and server push. HTTP/3 (based on QUIC) replaces TCP with UDP for faster connection establishment and better performance on unreliable networks — especially beneficial for mobile users.
