Internet Terminology

Web 1.0

Web 1.0 refers to the first generation of the World Wide Web — characterised by static, read-only HTML pages where content was created by a small number of publishers and consumed passively by users.

Web 1.0

THE READ-ONLY WEB · 1991–2004

Web 1.0 era — static HTML pages, Netscape browser, limited interactivity

What is Web 1.0?

Web 1.0 describes the earliest phase of the World Wide Web, roughly from 1991 to 2004. Pages were primarily static — flat HTML files stored on servers and delivered unchanged to every visitor. Content was created by website owners; users could only read, not contribute. The term 'Web 1.0' was coined retroactively to contrast with Web 2.0.

Technical Characteristics

Web 1.0 sites used basic HTML with table-based layouts, inline styles, frame-based navigation, and minimal JavaScript. Pages were often designed in fixed widths for 800×600 screens. Common elements included hit counters, GIF animations, guestbooks, and 'Under Construction' banners.

Business Model

The Web 1.0 era saw the dot-com boom (1995–2000) and bust (2000–2001). Early business models focused on advertising via banner ads (CPM-based). Most companies built a 'web presence' primarily as an online brochure. E-commerce pioneers like Amazon and eBay emerged during this period.

Key Technologies

Core technologies included HTML 3.2/4.0, early CSS, CGI scripts for minimal interactivity, Perl and early PHP for server-side scripting, dial-up modems (56Kbps), and browsers such as Netscape Navigator and Internet Explorer. Images were kept small for slow connections.

Legacy

Web 1.0 established the fundamental architecture of the Web: HTTP, HTML, URLs, and the client-server model. Many concepts introduced then — hyperlinks, forms, cookies — remain foundational today. It proved that the Internet could become a mainstream global information platform.
