Web Servers

A web server is software (and often the hardware it runs on) that accepts HTTP requests from clients and responds with web resources — the backbone of every website on the Internet.

What is a Web Server?

A web server is software that listens on a network port (typically port 80 for HTTP and 443 for HTTPS), receives client requests, processes them, and serves back resources such as HTML pages, images, CSS, JavaScript, or data. Common web servers include Apache HTTP Server, Nginx, Microsoft IIS, and Caddy.

Static vs Dynamic Content

Web servers can serve static content — pre-existing files returned as-is — or dynamic content, generated on-the-fly by server-side scripts (PHP, Python, Node.js, Ruby). Dynamic servers interact with databases and application logic to personalise responses per request.

HTTP Request Handling

When a browser requests a URL, the web server: (1) receives the TCP connection, (2) parses the HTTP request line and headers, (3) locates the requested resource, (4) constructs an HTTP response with status code and headers, and (5) sends the response body back to the client.

Virtual Hosting

A single physical server can host multiple websites through virtual hosting. Name-based virtual hosting uses the HTTP Host header to determine which site to serve, allowing one IP address to handle thousands of different domains.

Server Hardware

Web server hardware ranges from a Raspberry Pi for personal projects to massive data centre rack servers. Cloud providers (AWS, Azure, Google Cloud) offer virtual machines and managed server solutions. Key hardware metrics include CPU, RAM, storage I/O, and network bandwidth.
