Topic 1 — Internet Fundamentals

Internet Terminology
Reference Guide

A comprehensive, multi-page reference covering 16 foundational Internet and Web technology terms — from TCP/IP to Web 4.0.

Browse All 16 Terms

🌐
World Wide Web
WWW
The global system of interlinked hypertext documents accessed via the Internet.
🔗
TCP/IP
TRANSMISSION CONTROL PROTOCOL / INTERNET PROTOCOL
The foundational communication protocols of the Internet.
🖥️
Web Browsers
CLIENT SOFTWARE
Applications that retrieve, present and traverse resources on the Web.
🗄️
Web Servers
HTTP SERVER
Software and hardware that serves web content to clients on request.
📎
URLs
UNIFORM RESOURCE LOCATORS
Addresses used to identify resources on the Internet.
📡
DNS
DOMAIN NAME SERVER
The phone book of the Internet, translating names to IP addresses.
↔️
HTTP
HYPERTEXT TRANSFER PROTOCOL
The protocol for transmitting hypermedia documents on the Web.
🏢
Intranet
PRIVATE NETWORK
A private network that uses Internet technologies within an organisation.
🤝
Extranet
EXTENDED PRIVATE NETWORK
A controlled private network allowing external partner access.
🏗️
Multitier Architecture
N-TIER / THREE-TIER
A client-server architecture with logically separated layers.
📁
FTP
FILE TRANSFER PROTOCOL
A standard protocol for transferring files between a client and server.
📝
HTML
HYPERTEXT MARK-UP LANGUAGE
The standard language for structuring content on the Web.
1️⃣
Web 1.0
THE READ-ONLY WEB · 1991–2004
The first era of the Web — static pages and one-way information delivery.
2️⃣
Web 2.0
THE SOCIAL WEB · 2004–PRESENT
The interactive, user-generated-content era of the Web.
3️⃣
Web 3.0
THE SEMANTIC / DECENTRALISED WEB
The next Web — intelligent, decentralised and machine-readable.
4️⃣
Web 4.0
THE SYMBIOTIC WEB
The emerging Web — AI-driven, immersive and deeply integrated.
