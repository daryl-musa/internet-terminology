File Transfer Protocol

FTP (File Transfer Protocol) is a standard network protocol used to transfer files between a client and server over a TCP/IP network — one of the oldest Internet protocols, predating the Web itself.

What is FTP?

File Transfer Protocol (FTP) is an application-layer protocol for transferring files between hosts over a TCP network. Defined in RFC 959 (1985), it predates the World Wide Web. FTP uses two separate channels: a command channel (port 21) for control instructions and a data channel (port 20) for actual file transfer.

How FTP Works

An FTP session begins when the client connects to the server's port 21 and authenticates (username/password or anonymous login). The client can then issue commands: LIST (show files), RETR (download), STOR (upload), DELE (delete), MKD (make directory), and more. Data is transferred in either ASCII or binary mode.

Active vs Passive Mode

In active mode, the server initiates the data connection back to the client — problematic with firewalls. In passive mode (PASV), the server opens a port and the client initiates both connections, which is firewall-friendly and the default for modern FTP clients.

FTP Security Concerns

Standard FTP transmits data — including usernames, passwords, and file contents — in plain text, making it vulnerable to eavesdropping. FTPS (FTP Secure) adds TLS encryption. SFTP (SSH File Transfer Protocol) is a completely different protocol that provides encrypted file transfer over SSH and has largely replaced FTP for secure transfers.

FTP Today

While FTP usage has declined with the rise of HTTPS, cloud storage, and SFTP, it remains in use for legacy systems, web hosting control panels (uploading website files), automated batch file transfers, and situations where simplicity and broad support matter more than modern security.
