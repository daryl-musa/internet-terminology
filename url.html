What is a URL?

A Uniform Resource Locator (URL) is a standardised address for resources on the Internet. It was defined by Tim Berners-Lee as part of the Web's original architecture. Every web page, image, video, and API endpoint has a unique URL that identifies its location and how to access it.

Structure of a URL

A URL consists of several parts: the scheme (e.g., https://), the host (domain name or IP address), an optional port number (:8080), the path (/folder/page.html), an optional query string (?key=value), and an optional fragment (#section). Each part serves a specific purpose in locating the resource.

URL vs URI vs URN

A URI (Uniform Resource Identifier) is the broadest category — it identifies a resource. A URL is a URI that also specifies how to access it (location + protocol). A URN (Uniform Resource Name) identifies a resource by name regardless of location (e.g., ISBN numbers).

URL Encoding

URLs can only contain certain characters. Special characters (spaces, &, =, #) must be percent-encoded — replaced by % followed by their hexadecimal ASCII code. For example, a space becomes %20. This ensures URLs are transmitted correctly over HTTP.

Best Practices

Well-designed URLs are human-readable, stable, and descriptive. Search engines use URL structure as a ranking signal. Best practices include using hyphens (not underscores) between words, lowercase letters, meaningful path segments, and avoiding unnecessary parameters.
