Internet Terminology

Intranet

An intranet is a private, restricted computer network that uses Internet technologies (HTTP, HTML, TCP/IP) exclusively for an organisation's internal communication and resource sharing.

What is an Intranet?

An intranet is a private network accessible only to an organisation's staff. It uses the same technologies as the public Internet (web browsers, HTTP, HTML) but is isolated behind firewalls and access controls. It serves as an internal information hub, communication platform, and collaboration tool.

Key Uses of Intranets

Organisations use intranets for HR portals (policies, payslips, leave applications), document management, internal news and announcements, employee directories, project management tools, training materials, and communication tools like internal forums or wikis.

Intranet vs Internet

The Internet is a global public network open to everyone. An intranet is a private network accessible only to authorised users within an organisation. Access is typically restricted by firewalls, VPN requirements, and authentication systems.

Security Considerations

Intranets implement multiple security layers: firewalls to block external access, user authentication (username/password, SSO), role-based access control (RBAC) limiting access to sensitive data, encrypted connections (HTTPS even internally), and audit logging.

Benefits for Organisations

A well-designed intranet improves internal communication, reduces email overload, centralises information reducing duplication, increases productivity, preserves institutional knowledge, and supports remote workers through VPN-accessed internal resources.
