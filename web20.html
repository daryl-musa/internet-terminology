Web 2.0

Web 2.0 describes the second generation of the Web — characterised by user participation, social networking, dynamic content, and the shift from static pages to interactive, collaborative web applications.

Web 2.0

THE SOCIAL & PARTICIPATORY WEB · 2004–PRESENT

Web 2.0 — social platforms, user content, rich internet applications

What is Web 2.0?

Web 2.0, a term popularised by Tim O'Reilly and Dale Dougherty in 2004, describes the transformation of the Web from a read-only medium to a read-write platform. Users no longer just consume content; they create, share, comment, and interact. Social media, wikis, blogs, and collaborative platforms define this era.

Key Technical Innovations

Ajax (Asynchronous JavaScript and XML) was the pivotal technology enabling dynamic page updates without full reloads — pioneered by Google Maps and Gmail in 2005. Other enablers include REST APIs, JSON, CSS frameworks, the JavaScript explosion (jQuery, then Node.js), HTML5, and broadband adoption.

Social and Platform Economy

Web 2.0 gave rise to major platforms: Facebook (2004), YouTube (2005), Twitter (2006), iPhone (2007), Airbnb (2008), Uber (2009), Instagram (2010). The 'platform economy' emerged — companies whose primary value is facilitating interaction between users (network effects). The dominant business model became targeted advertising.

User-Generated Content

Wikipedia, Reddit, YouTube, TikTok, and review sites demonstrate UGC at scale. The Long Tail theory (Chris Anderson, 2004) described how Web 2.0 platforms could profitably serve niche interests at scale. The Wisdom of Crowds enabled collaborative filtering, recommendations, and collective intelligence.

Concerns and Criticisms

Web 2.0 also brought challenges: centralisation of power in a few large platforms, filter bubbles, misinformation, data privacy concerns (Cambridge Analytica scandal), attention economy manipulation, and content moderation difficulties. These concerns have driven interest in Web 3.0 decentralisation.
